# Romantic-Relationships-and-Careers-in-Academia
This survey investigates how romantic relationships, partner characteristics and partner support relate to academic careers and experiences.

Data were collected through a cross-sectional online survey, administered in English using REDCap between 16 June and 21 July 2025. Professors affiliated with Swiss higher education institutions were invited by email. Participation was voluntary and anonymous, and respondents provided informed consent.

This repository documents the survey and provides analysis scripts, replication instructions and supplementary results:
- Survey Design: ethics documentation, the full questionnaire and recruitment email invitations.
- Study-specific folders: analysis code, manuscripts and supplementary outputs for each study using the dataset.

Participant-level data are not included and are available upon request from the corresponding authors.
